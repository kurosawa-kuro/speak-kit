# 01 要件

出典は [英会話アプリ-コミュニティ配布を先に作り次段階へコピーする.md](./英会話アプリ-コミュニティ配布を先に作り次段階へコピーする.md)（2026-10-13）。ここには確定した範囲だけを置く。未決は末尾に残し、実装で埋めない。アプリ本体は未着手である。

## 目的

英会話コミュニティの知人に、個人の英会話練習アプリを GitHub 経由で渡す。各自が自分のアカウントで動かす。コア機能は AI キー無しで最後まで通り、Claude API は任意の拡張である。

live の毎日の学習は private-ops 内の `skill-trainer` に残す。このリポジトリの変更を live へ載せない。`speak-next`（Phase 2 移行の発展アプリ）は、`speak-kit` ができてからこのリポジトリをコピーして切る。今は切らない。

## 範囲

対象:

- 独立 GitHub リポジトリ（private-ops とは別 repo）
- 対象ユーザーは英会話コミュニティの知人（不特定少数〜中規模）
- 英会話練習（テキスト／音声）。コアは AI キー無しで動作し、Claude API は任意
- AI が未設定・失効・レート制限・到達不可でも、コア操作が最後まで通る
- アカウント作成からデプロイ、日常運用までの手順を YouTube 動画として公開する（クラウド手順はローカル動作の次）

非対象:

- private-ops の既存アプリとの統合
- 本番 `skill-trainer` の機能移植、適応訓練エンジン、Retool、ローカル Postgres を実装基盤にすること
- private-ops の個人運用ルール（ローカル Postgres 正本、無料枠原理、API-less）をこの公開配布アプリへそのまま適用すること
- `speak-next` の作成、コピー後の変更を `speak-kit` へ戻すこと、private-ops への吸収
- 本格的な商用化
- AI フィードバックの精度そのもの（ここが扱うのは「無くても壊れない」こと）
- 談話訓練（黒澤思考OS）、新しい Phase 番号、Phase 1 Gate への要件追加、Skill / Exercise の登録
- live の学習者データベースへの書き込み、障害修正以外のエンジン変更・マイグレーション・Retool publish

## ユーザー

- 一次ユーザー: 英会話コミュニティの知人。自分の GitHub、自分の Vercel、自分の Supabase、任意で自分の Anthropic API キーを使う。
- 黒澤の名義の課金・鍵・DB に、相手のアクセスや利用量を載せない（owner 決定 2026-10-11）。
- 単一ホスト型（黒澤がホストして友人に共有する形）は不採用。

## ユースケース

| ID | ユースケース | 成功条件 |
|---|---|---|
| UC-001 | AI キー無しでフレーズ練習を最後まで行う | 読み上げ、録音比較、学習記録（お気に入り）が完了する。AI UI は disabled と案内になり、クラッシュ・白画面・未処理エラーが出ない |
| UC-002 | Anthropic キーを設定し、任意の AI 機能を使う | 自由対話、文法／自然さフィードバック、シナリオの動的生成が、サーバー側 proxy 経由で動く。クライアントにキーを渡さない |
| UC-003 | AI 呼び出しが失敗してもコアを続ける | 401 / 429 / 5xx / timeout が、コアの API と画面へ伝播しない |

動画の最初のステップは UC-001 で完結させる。UC-002 は後続ステップである。

## Critical User Journey / Golden Path

一次ユーザーは、英会話コミュニティの知人である。目的は、自分の環境で AI 無しのフレーズ練習を最後まで通すこと。

完了状態: フレーズの読み上げ、自分の録音との比較、学習記録（お気に入り登録）が済み、AI 機能は disabled と案内のまま画面が残っている。

| # | ステップ | 成功条件（観測可能な状態） |
|---|---|---|
| 1 | AI キー無しでアプリを開く | AI 機能が最初から disabled。案内文がある。クラッシュしない |
| 2 | 固定スクリプト／フレーズ集を読み上げて練習する | 読み上げが最後まで実行できる |
| 3 | 自分の発話を録音し、再生して比べる | 録音と再生比較が完了する |
| 4 | 学習記録またはお気に入りを残す | 記録が保存され、あとから確認できる |

この一本が切れたらプロダクトは未達である。UC-002 は Golden Path の外にある。

- 構成要素への写像は [02_architecture.md](./02_architecture.md)。
- リリース時の smoke は [08_release_runbook.md](./08_release_runbook.md)。クラウド手順はローカルでこの一本が通ったあとである。

## 未決

アイディアノートの「未決（speak-kit）」を実装で埋めない。

- コア機能の具体的な中身をどこまで作るか（フレーズ集の素材）
- 公開範囲（完全招待制か、誰でも使えるか）
- 音声入出力の実装方法（Web Speech API か、別の STT/TTS か）
- 会話ログの保存要否とプライバシー方針
- GitHub テンプレートリポジトリ化の範囲（env サンプル、セットアップ README、CI）
- 動画の手順と実際のセットアップ手順の一致
- 開発用インスタンスの持ち方（黒澤自身も配布先の 1 人として別アカウントで動かす想定）
- `speak-kit` のどこまでを「できた」とみなし、`speak-next` をコピーしてよいか
