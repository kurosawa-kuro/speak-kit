# 元の英会話学習の計画・記録・会話を写す

## Weight Class

- Class: Heavy
- Reason: 今日の計画、文字回答の証拠、クイズ昇格、会話セッション、記録集計を、参照元の挙動へ戻す。ローカルの `speak_kit` に習得の行を書く。
- Limits: live DB、Supabase への SQL、Vercel、secret のコミットは 0。
- Owner approval required: yes。owner が修正作業を指示したので `03_active/` にある。26 箇所が全部観測できるまで完了にしない。

## Goal

`private-ops` の学習｜英会話（画面は `frontend/retool/app-mirror/skill-trainer/frontend`、動作は `apps/skill-trainer`）と同じ訓練のループを、speak-kit のローカル Postgres 上で通す。対象は 2026-10-13 に列挙した 26 箇所。画面の並びを作り直す作業ではない。

## Value

- integrity: 選択クイズと解説カードだけで、会話を作る訓練が完了扱いにならないようにする

## Scope

参照元は読むだけ。写す単位は次の 26。完了は、各項目が参照元と同じ入出力か同じ画面文言で観測できること。

今日:

1. 今日の計画は、診断・練習・確認の予算、定着確認、習得済みの飛ばしで選ぶ。カタログ先頭の「測る」3件で代用しない。
2. 重点の成功率、回答時間、採点件数、確かさは、空の選択スナップショットではなく実測から出す。
3. 期限の来た混同を今日の課題に載せる。
4. 「次は自分で言ってみる」は、クイズ昇格、または直近の言い出し失敗から最大3件出す。意味クイズの成功だけでは選ばない。
5. 「会話で使う」は、自分で言える成功が基準を満たし、会話成功が無い表現を出す。常に空にしない。
6. 「練習を始める」と次にやることの行は、今日の課題、またはその表現の実践練習を開く。練習画面へ移るだけでは完了にしない。
7. 形の `{slot}` は「...」にして見せる。

書いて答える:

8. 「回答する」は回答、採点、習得の証拠を保存し、今日の計画の課題を進める。画面の判定だけで終えない。
9. `skill_trainer_submit_attempt_v2` の free_text は、キーがあるとき参照元と同じ採点を通す。キーが無いときは即返し、choice を待たせない。
10. 確認できなかった回答は再判定できる。`skill_trainer_regrade_attempt_v2` を、キーが無いとき即返す以外の理由で塞がない。
11. 自由練習は、指定の表現を出し、習得済みの文を飛ばし、課題を実体化する。モードの無作為1件で代用しない。
12. 記録の「書いて答える」は、記述の正答と件数を出す。常に0件にしない。
13. 「この二つが混ざる」は境界の草案と確認問題を作り、確認の提出が `probe not found` だけで終わらない。

クイッククイズ:

14. 間隔を空けた2回成功で昇格し、「次は自分で言ってみよう」を出す。初回回答を常に未昇格にしない。
15. 昇格した表現を名指しし、その表現の実践練習へ渡す。「正解です / 違います」だけにしない。
16. 「文を選ぶ」を置き、意味か用途の成功があるまで出さない。

会話:

17. 開始、発言、終了を会話セッションとして残す。画面の中だけのチャットで代用しない。
18. 自発質問、フォロー、聞き返し、停止、日本語への切り替えを数える。
19. 「会話を終了する」で、ターン数、分数、各指標、言えなかった候補件数を出す。
20. 停止場面から候補を作り、承認か却下を残す。

記録:

21. 今週は、練習日、会話、新しく安定、克服、応答時間を週で集計する。回答回数以外を0のままにしない。
22. 表現ごとの能力、測定状態、診断を出す。
23. 会話の記録を出す。個別の習得度へは直接加点しない。
24. 取り違えた対ごとに、選ぶ正答と書く正答を出す。件数だけで終えない。
25. 正解済みは習得した文の数、再チェック期限は期限の数にする。クイズの安定数で代用しない。
26. 採点源の内訳と、Phase 1 の通過判定を、参照元の集計で出す。常に未通過に固定しない。

キー unset の choice 経路は、完了済みタスク `05_done/2026-10-13-local-text-golden-path.md` のまま通る。choice は採点モデルを呼ばない。

## Risk

- 画面文言だけ揃えて、証拠の行が残らないと、記録の26箇所は再発する。
