## 用語

| 用語 | 意味 |
|---|---|
| speak-kit | このリポジトリ。英会話コミュニティへ配るアプリ。配る相手のアカウントで動かす |
| speak-next | `speak-kit` ができてから、このリポジトリをコピーして切る発展側。Phase 2（外資面接）の開発場所。コピー後の変更は `speak-kit` へ戻さない |
| skill-trainer | 参照元アプリ。パスは `/Users/kurosawa/Dev/private-ops/apps/skill-trainer`。Phase 1 の毎日の学習はここに残す。`speak-kit` の実装は、この crate の挙動・SQL・ドメイン文言を限りなくコピーし、Rust API だけを Next.js へ書き直す。変更は live へ戻さない |
| 配布型 | 各自が自分の GitHub・Vercel・Supabase・任意の Anthropic キーでデプロイする。確定 |
| 単一ホスト型 | 黒澤がホストして友人に共有する形。不採用 |
| コア | AI 無しで動く範囲。テキストのフレーズ練習、学習記録・お気に入り。音声入出力は含まない |
| 公開範囲 | そのインスタンスを誰が使えるか。決定は利用者一人。AI 悪用防止のため、複数人や誰でも使える形にはしない |
| 一人用 | 各デプロイはプライベートアプリ一つ。知人への配布は、各自が自分の一人用インスタンスを立てることである |
| オプション AI | Claude との自由対話、文法／自然さのフィードバック、シナリオの動的生成。キーが無いと無効 |
| aiEnabled | サーバーがクライアントへ返す boolean。キー文字列そのものは返さない |
| 学習記録 | コアの保存対象。お気に入り登録を含む。会話ログを保存するかは未決 |
| live の学習者 Evidence | 現行データベースに残る。`speak-kit` も開発中の `speak-next` も、そこへ書かない |

## 状態 / ライフサイクル

AI 機能の見え方は、キーの状態で次のように分かれる。コアの状態とは独立である。

```text
キー未設定
  -> AI 機能は最初から disabled + 案内
  -> コアは操作できる

キーが有効
  -> AI エンドポイントだけが Claude を呼ぶ
  -> コアは引き続き AI を import しない

キーが無効 / 429 / 5xx / timeout
  -> その AI 呼び出しだけが失敗
  -> コアの操作はエラーにならない
```

リポジトリのライフサイクル:

```text
speak-kit を作る
  -> ローカルでコアが通る
  -> （別ステップ）各自のクラウドへ配布できる
  -> speak-kit ができたあと、コピーして speak-next を切る
  -> コピー後の変更は speak-kit へ戻さない
```

「できた」の線、コピー後にどちらへ足すか、`speak-next` のデータベース、private-ops へ吸収する条件は未決である。
